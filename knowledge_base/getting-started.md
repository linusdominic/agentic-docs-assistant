# Getting started with Nimbus Notes

Nimbus Notes is a note-taking app for the web, macOS, Windows, iOS and Android. Notes sync between your devices and are stored as plain Markdown.

## Create an account

Sign up at the Nimbus Notes website with an email address and a password of at least 12 characters. A verification link is emailed to you and stays valid for 24 hours. You can start writing before you verify, but sync is switched on only after verification.

## Install the apps

The desktop apps need macOS 13 or later, or Windows 10 version 22H2 or later. The mobile apps need iOS 17 or Android 12 and later. On Linux, use the web app in any current browser.

## Notebooks, notes and tags

Notes live inside notebooks. A notebook can contain other notebooks, up to five levels deep. A note belongs to exactly one notebook but can carry any number of tags, so use notebooks for where a note lives and tags for what it is about.

## Keyboard shortcuts

On macOS, press Cmd+N for a new note, Cmd+K to search everything, and Cmd+Shift+M to move the current note. On Windows, use Ctrl in place of Cmd. Press Cmd+/ to see the full list inside the app.

## Importing existing notes

Nimbus Notes imports Markdown folders, Evernote `.enex` exports and Apple Notes archives. Open Settings, choose Import, and pick the source. Imports of up to 5,000 notes usually finish in under ten minutes. Attachments larger than the plan's file limit are skipped and listed in the import report.
